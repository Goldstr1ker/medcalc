# МедКалк

Клинические калькуляторы и шкалы с разбором по клиническим рекомендациям.
Русский язык, единицы СИ по умолчанию, работает офлайн.

## Запуск

```bash
npm install
npm run dev
```

Откроется на http://localhost:5173

## Проверки

```bash
npm run validate   # схема калькуляторов
npm test           # формулы (examples из каждого калькулятора)
npm run check      # и то, и другое
```

Обе проверки запускаются автоматически перед `npm run build` и в CI, поэтому
битая схема или разъехавшаяся формула не доедут до Pages.

**Зачем валидатор.** Поломка схемы здесь тихая: опечатка в ключе
(`guidance: { hgih: … }` вместо `high`) ничего не роняет — просто блок «По
клиническим рекомендациям» не отрисуется, и пользователь об этом не узнает.
Валидатор ловит: дубли `id`, ключи `interpretation`/`guidance`, не совпадающие
с диапазонами, раздел вне `src/lib/systems.js`, единицы без `factor`,
отсутствующие обязательные поля и примеры.

**Зачем тесты.** `examples` в каждом калькуляторе — это одновременно защита от
регрессий и живая документация с клиническими примерами. Тесты гоняют тот же
конвейер, что и приложение (`src/lib/compute.js`), и сравнивают **округлённое**
значение — то, которое реально появится на экране.

## Сборка

```bash
npm run build      # -> dist/, статические файлы, деплой куда угодно
npm run preview    # локальный просмотр сборки
```

## Деплой

Автоматический на GitHub Pages: пуш в `main` запускает
`.github/workflows/deploy.yml` (сборка + публикация).
Живой адрес: https://goldstr1ker.github.io/medcalc/

Один раз включить в репозитории: **Settings → Pages → Build and deployment →
Source: GitHub Actions**.

Роутинг — по hash (`#/calc/<id>`), `base: './'` в `vite.config.js`, поэтому
подпапка `/medcalc/` работает без доп. настройки и SPA-fallback не нужен.

## Как добавить калькулятор

Создать файл `src/calculators/<раздел>/<id>.js` с `export default` объектом.
Реестр (`src/registry.js`) подхватит его автоматически — больше ничего править не нужно.

Минимальная схема:

```js
import { SYSTEMS } from '../../lib/systems.js';
import { CREATININE_MGDL } from '../../lib/units.js';

export default {
  id: 'unique-id',
  name: 'Полное название',
  shortName: 'Короткое',            // необязательно
  system: SYSTEMS.NEPHROLOGY,       // только из src/lib/systems.js
  tags: ['ключевые', 'слова'],      // для поиска
  description: '...',

  inputs: [
    { id: 'sex', label: 'Пол', type: 'select', options: ['Мужской', 'Женский'] },
    { id: 'age', label: 'Возраст', type: 'number', unit: 'лет', min: 0, max: 120 },
    // Наборы единиц берутся из src/lib/units.js, а не пишутся инлайном:
    // суффикс константы = единица, в которой значение придёт в calculate().
    { id: 'scr', label: 'Креатинин', type: 'number', units: CREATININE_MGDL },
    { id: 'flag', label: 'Признак есть', type: 'boolean' },
  ],

  // получает канонические значения (единицы уже переведены)
  calculate(v) {
    return {
      value: 42,
      unit: 'мл/мин/1,73 м²',       // для type: 'score' не нужно
      decimals: 0,
      breakdown: [{ label: 'За что балл', points: 1 }],  // необязательно, для score
    };
  },

  result: {
    type: 'gauge',                  // 'gauge' | 'score' | 'value'
    min: 0, max: 120,               // для gauge
    // max: 9,                      // для score
    bands: [
      { id: 'norm', label: 'Норма', min: 90, color: 'green' },
      { id: 'low',  label: 'Снижение', min: 0, color: 'red', risk: '≈2% в год' },
    ],
  },

  interpretation: { norm: '...', low: '...' },        // обязателен для КАЖДОГО band'а
  guidance: {                                          // «по клинрекам это значит…»
    low: { source: 'КР ... , 2021', points: ['...', '...'] },
  },
  caveats: ['Ограничение 1', 'Ограничение 2'],         // необязательно

  // Обязательны: без них формула ничем не защищена от регрессий.
  // Указывайте только те поля, что отличаются от значений по умолчанию.
  examples: [
    {
      note: 'Мужчина 60 лет, креатинин 180 мкмоль/л — стадия С3б',
      inputs: { sex: 'Мужской', age: 60, scr: 180 },
      units: { scr: 'umol' },        // необязательно, по умолчанию первая единица
      expect: { value: 37, band: 'C3b', details: [] },  // value — ОКРУГЛЁННОЕ, как на экране
    },
  ],

  references: ['Автор и т.д. Журнал. Год.'],
  updated: '2026-09-04',
  version: 1,
};
```

Цвета band'ов: `green`, `lime`, `yellow`, `orange`, `red`, `darkred`, `slate`.

Хорошие `examples` покрывают: типичный случай, обе крайности шкалы, границы
диапазонов и любую нетривиальную логику формулы (ограничения сверху/снизу,
переключение единиц, коэффициенты по полу).
